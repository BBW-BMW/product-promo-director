# 产品宣传视频导演 · Product Promo Director

**面向 30 秒至 2 分钟产品宣传片的 AI 视频导演工作流。** 从产品官网、UI、录屏和已有脚本出发，先选择创意方向与时长，再完成参考研究、详细脚本分镜、AI 视频生成专用 Prompt、逐镜制作、连续性验收与最终交付。

适用于 AI 产品、SaaS、软件、桌面应用和单功能发布。既可完成从零制作，也可以只执行找参考、写脚本、做关键帧、制作 AI 视频提示词或修改已有视频。

**调用名称：`$product-promo-director`**  
更新日期：2026-10-30

## 快速开始

在已安装并启用此 Skill 的环境中，输入：

```text
使用 $product-promo-director，为 https://www.seavideo.tv/ 做一条产品宣传视频。
```

Skill 不会立刻生成视频，而会分析产品，给出 **A / B / C 三个有明显区别的创意方向**，并提供四档视频时长。用户可以一次完成选择：

```text
我选择 B + 1:30。先输出完整脚本、分镜和 AI 视频详细生成提示词，不要直接生成成片。
```

如果用户直接指定了合法时长（如“制作 60 秒”），则不会再次询问时长；如果已有确认的创意方案，也无需重复选择。默认只在用户**单独调用 Skill 名称、询问怎么使用或主动要求目录**时展示 8 项使用菜单。

**重要：**普通的“帮我做视频”“直接做”不会跳过创意方向选择；明确表示“不要给方案，风格由你定”时可以跳过方向选择，时长仍需单独确认或授权自选。**只有方向和时长都确定后**才会进入完整制作。

> 只访问或收藏 GitHub 仓库不会自动启用 Skill。使用时需按照所处环境的安装方式加载本仓库，主入口为 [SKILL.md](SKILL.md)。

## 使用入口

| 编号 | 我想做什么 | 本轮主要输出 |
|---|---|---|
| 1 | 从零制作宣传视频 | 先给3个创意方向＋4档时长选项，两个都确认后才制作 |
| 2 | 找参考、选视频风格 | 同类作品、可取得的真实截图或封面、推荐方向 |
| 3 | 写脚本与口播文案 | 叙事结构、标题、口播与字幕 |
| 4 | 先看视觉效果 | 开场、功能展示、收尾的 2–3 张关键帧 |
| 5 | 制作完整分镜 | 时间、画面、文字、动作、转场与声音分镜表 |
| 6 | 生成AI视频详细剧本与提示词 | 分镜后逐镜导演剧本、模型执行Prompt及15秒段级生成包 |
| 7 | 准备录屏与制作成片 | 逐镜录制清单、软件建议、动效合成与导出 |
| 8 | 修改或续做已有视频 | 保留已确认部分，处理指定镜头与相关衔接 |

用户只要某个阶段时，交付范围就停在该阶段。图片、配音、动态与成片制作取决于实际工具和素材条件。

## 三方向与四档时长

### 创意方向

新视频制作首次调用时，从内置8类风格中根据产品推荐 **3 个真正不同的方案（A / B / C）**。每个方案说明创意主张、适用场景、叙事主线、视觉构图与材质、代表镜头、素材需求、制作难度及推荐理由。

方向可单选，也可以按用户要求混合。**推荐方向不等于用户已确认。**

### 视频时长

**单条最长2分钟（120秒），支持以下四个标准档位：**

| 选项 | 时长 | 推荐用途 | 15 秒逻辑段数 |
|---|---|---|---|
| 1 | **0:30（30 秒）** | 品牌预告、核心卖点 | 2 |
| 2 | **1:00（60 秒）** | 产品介绍、主要功能 | 4 |
| 3 | **1:30（90 秒）** | 多功能串联、典型场景 | 6 |
| 4 | **2:00（120 秒）** | 更完整的产品故事、多场景展示 | 8 |

选择示例：`A + 0:30`、`B + 1:30` 或 `C + 2:00`。

已指定合法时长不重复问；用户只确认了一项就只补充另一项。超出2分钟时，建议改为2:00或拆成多条独立视频；非四档时长不擅自替换。90秒与120秒方案需要增加有效的故事章节和功能画面，**不能把30秒六镜模板机械放慢**。

这里的“15秒”是**时间线组织的逻辑单位**，不是宣称某个视频模型能一次生成15秒。模型实际单次生成较短时，必须按能力拆成短片合成。

## 完整制作流程

新任务先经过 **产品分析 → A/B/C 方向选择 + 时长确认**，随后按下表推进制作。仓库主 Skill 使用编号1–9，并在第6阶段后新增 **6A**，以确保详细生成提示词不会被跳过。

| 阶段 | 主要工作 | 阶段产物 |
|---|---|---|
| 1 · 产品需求 | 确认定位、受众、用途、必展功能与真实素材 | 产品简报、素材清单 |
| 2 · 参考研究 | 检索同类官方宣传片、UI动效与真实演示，区分实际观看与静态参考 | 参考链接、借鉴与取舍 |
| 3 · 视觉定调 | 确定色彩、字体、材质、构图及运动语言；制作2–3张代表关键帧 | 开场/功能/收尾视觉关键帧 |
| 4 · 文案脚本 | 编写叙事结构、标题、口播与字幕；匹配目标时长 | 完整宣传脚本 |
| 5 · 功能映射 | 把每项核心功能对应到真实操作、页面状态或成果证据 | 功能到镜头映射 |
| 6 · 完整分镜 | 分配SH镜头ID、绝对时码、画面、运动、转场与声音 | 完整分镜与15秒分段计划 |
| **6A · AI生成详细剧本** | **逐镜写出起止帧、分秒动作、相机运动、负面约束和可复制模型Prompt** | **全片母提示词＋逐镜导演卡＋15秒段级生成词** |
| 7 · 逐镜制作 | 判断图生视频、文生视频、可控编辑或录屏；先做代表镜头测试 | 实际视频镜头及进度记录 |
| 8 · 画面与声音合成 | 连接片段、匹配动作与声音，添加可控文字及品牌内容 | 动态初稿、可用合成工程 |
| 9 · QA与交付 | 逐镜、跨段及整片检查，验证格式、时长和实际文件 | MP4、按要求提供的文档与可用工程 |

**用户可指定交付边界。** 例如“先给脚本、分镜、详细生成词”，则在6A完成后交付并停止，不自动生成视频。要求完整成片且工具素材齐备时，按授权继续，不附加每阶段强制确认。

关键帧审阅是**可选节点**：用户明确要求“先看效果”时展示关键帧并等待确认；用户已授权持续制作时无需重复打断。

## 八种参考风格

Skill 参考检索覆盖完整宣传片、UI动效和真实产品演示，可从 Behance、Vimeo、Dribbble、Pinterest、Launched.video、Awwwards、YouTube 和 Made with Motion 等来源查找案例。每个案例注明实际观看范围及证据状态；**封面/静帧不等于已验证动态效果**。

内置 **8种风格方向 + 48镜原创起步模板**。新视频会推荐其中最适合的3种进行对比：

| 风格编号 | 名称 | 适合的内容 |
|---|---|---|
| V01 | 浅色极简发布 | 高端软件、官网首屏、品牌发布 |
| V02 | 深色技术特写 | 开发工具、工程平台、技术AI |
| V03 | 字体节奏宣言 | 短版预告、品牌口号 |
| V04 | 彩色模块创作 | AI艺术、设计与创作平台 |
| V05 | 真实工作流演示 | 操作过程、单功能发布 |
| V06 | 空间生态总览 | 平台能力、多个工作空间 |
| V07 | 痛点与前后对比 | 效率提升、流程改进 |
| V08 | 数据与成果证明 | B2B产品、指标及真实成果 |

30秒模板是叙事起点，60/90/120秒需按内容重新规划，不机械拉长。示意图和原创模板不能冒充产品真实UI或已观看的视频片段。

## 需要准备的资料

不必一次准备齐全，已有信息会被复用。

| 资料 | 建议内容 |
|---|---|
| 产品信息 | 官网、功能介绍、PRD 或一句定位 |
| 传播目标 | 官网首屏、社交发布、产品发布会或功能演示 |
| 核心内容 | 受众、主要收益、必须展示的功能 |
| 视频规格 | 从0:30/1:00/1:30/2:00中选时长，另设横竖版、分辨率与帧率 |
| 品牌素材 | 最新 Logo、字标、字体、颜色与规范 |
| 产品画面 | 高清 UI、录屏、分镜图片与现有工程 |
| 声音要求 | 是否旁白、语言、音乐、音效与字幕 |
| 本轮交付 | 参考、脚本、关键帧、提示词、预览或 MP4 |

未指定画面规格可提出16:9、1080p、30fps等暂定建议；**时长不能默认为30秒**，要展示四选一并等待选择（除非用户明确授权自选）。声音按项目决定。

## 常用调用示例

### 从零规划，先看方案

```text
使用 $product-promo-director，为[产品链接]规划宣传视频。
面向[受众]，重点表达[核心收益]，必须展示[功能]。
先给参考方向和文案大纲，暂不制作整片。
```

### 找真实视觉参考

```text
使用 $product-promo-director，进入2号入口。
为[产品]寻找3–5个同类型视频参考。
展示能取得的真实画面、原始链接和具体借鉴方式。
我偏好浅色、简洁、自然材质；无法观看的案例单独标记。
```

### 只生成详细 AI 视频剧本与提示词

```text
使用 $product-promo-director，进入6号入口。
沿用已经确定的60秒脚本与全部上传分镜，不改镜头顺序和首尾。
请输出Global Master Prompt、每镜中文详细导演卡、可复制的模型执行版Prompt、
4个15秒逻辑段的分段生成剧本，写清起止帧、逐秒动作、机位和段间衔接。
本轮只要完整生成提示词，不生成视频。
```

### 确认方案后，继续完整制作

```text
使用 $product-promo-director。方向已确认：B；时长：1:30。
按照已确定的脚本和分镜，先生成逐镜AI视频详细剧本与模型Prompt，
再测试代表镜头、逐段制作、检查全部5处跨段衔接，最后合成90秒MP4。
保持真实产品UI和Logo不变；素材/工具不足时明确说明。
```

### 修改已有视频

```text
使用 $product-promo-director，进入8号入口。
修改[镜头ID/时间段]：界面太小，改成操作特写。
保持原文案、Logo、背景与其他镜头顺序。
检查修改镜头与前后转场，附简短修改记录。
```

## AI 视频生成详细剧本与提示词

这是此 Skill 的 **6A 阶段：完整脚本和分镜之后、实际视频生成之前的必经交付环节**。它不只是扩写分镜，而是把每个镜头转化为面向视频模型的可执行制作指令，尽量减少生成过程中人物/物体变形、UI伪造、运镜跑偏和跨段跳变。

| 交付层级 | 必须提供的内容 |
|---|---|
| **全片 Global Master Prompt** | 品牌色、Logo来源、角色/产品形态、场景光线、运镜语法及全片负面约束 |
| **逐镜中文导演详细剧本** | 每个SH镜头的叙事目标、时码、素材、起始帧、逐秒动作、主体与相机运动、结束帧、转场、口播字幕及失败重做策略 |
| **逐镜模型执行版 Prompt** | 可直接复制给指定视频模型的独立提示词；含 INPUT、CONSISTENCY、START、TIMELINE、CAMERA、END、DO NOT、POST |
| **15秒逻辑段生成剧本包** | 每个SEG段覆盖哪些镜头、相对时间、首末帧锚点、相邻段衔接及音频；模型单次生成不足15秒时再拆短clip |

**镜头制作分流：**`I2V`（图生视频）、`T2V`（文生视频）、`EDIT`（可控编辑/动画）、`RECORD`（真实录屏）。真实产品操作、精确UI、Logo、小字和字幕，应优先使用可靠录屏/截图或后期可编辑叠加，**不要用视频模型凭空伪造**。

模型选择按实际可用工具和当前核实的能力决定。若不支持首尾帧、参考图片或单次15秒生成，则调整短clip方案；不会把不存在的模型控制参数写成可执行命令。先小样测试，再逐镜制作。**详细提示词提高可控性，但不保证所有视频模型一次生成成功。**

完整规范与格式示例：[AI 视频详细生成词规范](references/video-generation-prompts.md)；项目表格：[制作模板](references/templates.md)。

## 制作质量控制

为了避免一口气生成长片带来的返工，Skill 在制作期间执行三项控制：

1. **关键帧可选审阅**：先有开场、功能和收尾的2–3张关键帧；用户要求先审图时停在待确认状态，修改通过再批量制作；用户授权完整制作则不增加强制确认。
2. **逐镜状态管理**：镜头以`SH-xx`稳定编号，记录素材、版本、文件、实际验收证据；按`待素材 → 待生成 → 待验收 → 已通过`推进，有缺陷标记`需重做`，优先局部返工。
3. **跨段连续性协议**：以`SEG-xx`管理每个15秒逻辑段，登记角色或产品外观、相机机位、背景与光照、UI/Logo状态、末帧/首帧和声音接口；逐个检查`SEAM-N/N+1`接缝，防止跳变、重复动作与音频断点。

**实际验收才算通过**：仅有脚本、图片或静态帧不能声称视频效果已验证。详细规则见 [制作控制协议](references/production-controls.md) 和 [验收清单](references/qa-checklist.md)。

## 录屏与交付

- macOS 录制产品演示时优先考虑 **Screen Studio**。
- Windows、Linux 或需要免费方案时考虑 **OBS Studio**。
- 已有习惯工具时沿用；根据操作系统与当前官方资料核实功能和获取方式。
- 录制前给出逐镜清单，先测试 10–15 秒，检查文字、指针、音频和分辨率。
- 区分原始素材与已经添加缩放、指针效果的演示片，避免后期重复包装。

可按需求交付参考方案、文案、分镜、关键帧、分段提示词、动态预览、MP4 与实际可提供的源工程。

**这是一套制作流程 Skill，本身不是独立的视频生成模型。** 成片、配音与工程导出依赖可用工具；要求 MP4 时，只有实际导出文件才算完成，HTML 预览或提示词不能代替 MP4。剪映等工程需实际导出并验证可打开后再宣称交付。

## 制作规则

- 当前产品要求优先于历史偏好，不把所有产品套成同一风格。
- 新宣传片先确认创意方向和四档之一的时长，单条最长120秒；长视频重新设计镜头密度，不机械拉长30秒模板。
- 展示既有功能时使用真实产品素材，概念画面不能冒充真实操作。
- 上传分镜保持组内、组间顺序、数量与首尾，不擅自删镜或合并。
- 按 15 秒拆分时保留角色/产品外观、相机、背景光线、UI/Logo与声音锚点；每个接缝逐一核对，避免漏镜、重复动作和突变。
- 默认避免连续 3 镜重复“左标题＋右截图＋淡入”，让状态变化承担信息。
- 精确文字优先使用可编辑文字，检查放大后的 UI 清晰度。
- 逐镜检查关键帧并完整播放；静态检查不能代替动态和音画同步验收。
- 不自动发布作品、投稿或发送给他人。

个人默认倾向简洁、黑白浅灰、少量品牌色、自然反射与平滑运动；可以针对单个项目调整。
