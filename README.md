# 产品宣传视频导演 · Product Promo Director

把产品官网、功能说明、UI 截图、录屏或已有分镜，整理成有明确视觉方向和叙事结构的产品宣传视频。

适用于互联网产品、AI 工具、SaaS 软件、桌面应用与单功能发布。你可以从零制作，也可以只完成参考、文案、关键帧、分镜或局部修改。

**调用名称：`$product-promo-director`**  
更新日期：2026-10-15

## 快速开始

在支持 Skill 的环境中安装本仓库的 Skill，并启用后，输入：

```text
使用 $product-promo-director
```

Skill 会先展示使用目录。回复编号或直接描述需求即可，也可以组合选择：

```text
2＋4，为这个产品找参考，再制作视觉关键帧。
产品链接：[填写链接]
这次先看视觉效果，不制作整片。
```

如果已经给出明确任务，Skill 会匹配对应入口并开始处理；继续已有项目时，不会反复展示欢迎目录或要求重填资料。明确说“直接做，不用目录”即可跳过引导。

> 仅访问或收藏 GitHub 仓库不会自动启用 Skill。安装方式取决于使用环境；核心入口文件是 [SKILL.md](SKILL.md)。

## 使用入口

| 编号 | 我想做什么 | 本轮主要输出 |
|---|---|---|
| 1 | 从零制作宣传视频 | 产品简报、参考方向、脚本分镜与后续制作 |
| 2 | 找参考、选视频风格 | 同类作品、可取得的真实截图或封面、推荐方向 |
| 3 | 写脚本与口播文案 | 叙事结构、标题、口播与字幕 |
| 4 | 先看视觉效果 | 开场、功能展示、收尾的 2–3 张关键帧 |
| 5 | 制作完整分镜 | 时间、画面、文字、动作、转场与声音分镜表 |
| 6 | 生成分段视频提示词 | 按镜头或 15 秒拆分的连续提示词 |
| 7 | 准备录屏与制作成片 | 逐镜录制清单、软件建议、动效合成与导出 |
| 8 | 修改或续做已有视频 | 保留已确认部分，处理指定镜头与相关衔接 |

用户只要某个阶段时，交付范围就停在该阶段。图片、配音、动态与成片制作取决于实际工具和素材条件。

## 完整制作流程

| 阶段 | 主要工作 | 阶段产物 |
|---|---|---|
| 1. 理解产品 | 梳理定位、受众、目标、必展功能与素材 | 产品简报、功能和素材清单 |
| 2. 查找参考 | 检索同类宣传片、UI 动效与真实产品演示 | 参考对比、视觉预览与适配建议 |
| 3. 确定视觉 | 提取品牌规范，设计 2–3 张关键帧 | 构图、色彩、字体、材质与运动方向 |
| 4. 编写文案 | 组织故事，分别处理标题、口播与字幕 | 文案稿与叙事结构 |
| 5. 映射功能 | 将卖点对应到真实页面、操作与结果 | 功能到镜头映射表 |
| 6. 编排分镜 | 分配时间，写清动作、转场与声音 | 完整分镜与分段方案 |
| 7. 逐镜制作 | 使用真实 UI、录屏、可控动效或生成素材 | 镜头素材、提示词或制作工程 |
| 8. 合成声音 | 拼接镜头，配合口播、音乐与音效 | 动态初稿 |
| 9. 验收交付 | 检查首尾、漏镜头、清晰度、连续性与音画同步 | 所需文件、验收与修改记录 |

可从已有脚本、分镜或视频继续，不必每次重走全部阶段。希望共同确定方向时，可说明“先给参考”“先看关键帧”；希望连续推进时，可说明“常规判断由你自主完成”。

## 参考与风格

参考分为三类：

- **完整宣传片：**研究叙事、镜头顺序、节奏与声音。
- **UI 动效与视觉设计：**研究界面登场、卡片变化、构图与局部转场。
- **真实产品演示：**研究操作过程、结果展示与录屏包装。

内置参考导航覆盖 Behance、Vimeo、Dribbble、Pinterest、Launched.video、Awwwards、YouTube 和 Made with Motion；根据任务选用，不要求每次遍历全部网站。

每个案例记录原始链接、作者、核验日期、实际观看范围、画面证据、借鉴项与适配限制。**封面、静帧和动态观看分别标记；尚未核验的候选案例不算已完成拆解。**

提供 8 种可选方向与 48 镜原创分镜起步模板：

| 风格 | 适合的内容 |
|---|---|
| 浅色极简发布 | 品牌发布、简洁的软件介绍 |
| 深色技术特写 | 开发工具、工程平台 |
| 字体节奏宣言 | 发布预告、短版品牌表达 |
| 彩色模块创作 | 设计与创作平台 |
| 真实工作流演示 | 实操、功能发布与上手演示 |
| 空间生态总览 | 多产品、多工作空间与平台关系 |
| 痛点与前后对比 | 流程改进、效率与迁移 |
| 数据与成果证明 | 分析产品、案例与真实成果 |

风格未定且需要比较时，通常推荐最合适的 3 种；只要一个方向时聚焦一个。模板和占位示意不是真实视频截图，也不是一键运行的成片组件。

## 需要准备的资料

不必一次准备齐全，已有信息会被复用。

| 资料 | 建议内容 |
|---|---|
| 产品信息 | 官网、功能介绍、PRD 或一句定位 |
| 传播目标 | 官网首屏、社交发布、产品发布会或功能演示 |
| 核心内容 | 受众、主要收益、必须展示的功能 |
| 视频规格 | 时长、横竖版、分辨率与帧率 |
| 品牌素材 | 最新 Logo、字标、字体、颜色与规范 |
| 产品画面 | 高清 UI、录屏、分镜图片与现有工程 |
| 声音要求 | 是否旁白、语言、音乐、音效与字幕 |
| 本轮交付 | 参考、脚本、关键帧、提示词、预览或 MP4 |

未指定时可提出 16:9、1080p、30fps 等暂定建议；时长与声音按项目决定。普通缺省项可以推断，无法推断的关键资料才需补充。

## 常用调用示例

### 从零规划，先看方案

```text
使用 $product-promo-director，为[产品链接]规划宣传视频。
面向[受众]，重点表达[核心收益]，必须展示[功能]。
先给参考方向和文案大纲，暂不制作整片。
```

### 找真实视觉参考

```text
使用 $product-promo-director，进入2号入口。
为[产品]寻找3–5个同类型视频参考。
展示能取得的真实画面、原始链接和具体借鉴方式。
我偏好浅色、简洁、自然材质；无法观看的案例单独标记。
```

### 按上传分镜生成提示词

```text
使用 $product-promo-director，进入6号入口。
严格按全部上传图片顺序生成提示词，总长60秒，分4段。
保留第一张空白页与最后品牌页，不漏镜头、不更换背景和Logo。
写清每段时间轴、首尾状态与衔接；本轮只要提示词。
```

### 制作并导出成片

```text
使用 $product-promo-director，为[产品]制作30秒宣传视频。
16:9，1920×1080，30fps。
必展功能：[填写]。
旁白：[填写]；音乐：[填写]；字幕：[填写]。
常规判断自主推进，本轮交付MP4及可提供的源工程。
工具或素材缺失时说明具体缺项。
```

### 修改已有视频

```text
使用 $product-promo-director，进入8号入口。
修改[镜头ID/时间段]：界面太小，改成操作特写。
保持原文案、Logo、背景与其他镜头顺序。
检查修改镜头与前后转场，附简短修改记录。
```

## 录屏与交付

- macOS 录制产品演示时优先考虑 **Screen Studio**。
- Windows、Linux 或需要免费方案时考虑 **OBS Studio**。
- 已有习惯工具时沿用；根据操作系统与当前官方资料核实功能和获取方式。
- 录制前给出逐镜清单，先测试 10–15 秒，检查文字、指针、音频和分辨率。
- 区分原始素材与已经添加缩放、指针效果的演示片，避免后期重复包装。

可按需求交付参考方案、文案、分镜、关键帧、分段提示词、动态预览、MP4 与实际可提供的源工程。

**这是一套制作流程 Skill，本身不是独立的视频生成模型。** 成片、配音与工程导出依赖可用工具；要求 MP4 时，只有实际导出文件才算完成，HTML 预览或提示词不能代替 MP4。剪映等工程需实际导出并验证可打开后再宣称交付。

## 制作规则

- 当前产品要求优先于历史偏好，不把所有产品套成同一风格。
- 展示既有功能时使用真实产品素材，概念画面不能冒充真实操作。
- 上传分镜保持组内、组间顺序、数量与首尾，不擅自删镜或合并。
- 按 15 秒拆分时保留跨段状态，避免漏镜、重复动作和突变。
- 默认避免连续 3 镜重复“左标题＋右截图＋淡入”，让状态变化承担信息。
- 精确文字优先使用可编辑文字，检查放大后的 UI 清晰度。
- 逐镜检查关键帧并完整播放；静态检查不能代替动态和音画同步验收。
- 不自动发布作品、投稿或发送给他人。

个人默认倾向简洁、黑白浅灰、少量品牌色、自然反射与平滑运动；可以针对单个项目调整。
