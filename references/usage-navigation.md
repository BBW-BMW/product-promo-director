# 使用目录与阶段引导

## 首次调用展示

仅在用户问如何使用Skill或主动要求目录时，展示下面的用户可读目录。用户直接要求为新产品制作宣传视频时，优先展示3个方向，并同时提供0:30 / 1:00 / 1:30 / 2:00四档时长让用户选择（已选时长不重复问），不先出片。

使用下面的用户可读目录。编号固定，与制作流程的9个阶段编号分开。不要向用户展示内部文件名、V编号或工具实现术语。

> 欢迎使用「产品宣传视频导演」。你可以从完整制作开始，也可以只完成其中一步。

| 编号 | 我想做什么 | 你会得到什么 |
|---|---|---|
| 1 | 从零制作宣传视频 | 先分析产品，选择A/B/C创意方向和0:30/1:00/1:30/2:00时长，再制作视频 |
| 2 | 找参考、选视频风格 | 同类视频链接、可取得的真实截图/封面、3个适合的方向 |
| 3 | 写脚本与口播文案 | 叙事结构、标题、口播与字幕文案 |
| 4 | 先看视觉效果 | 开场、功能展示、收尾的2–3张关键帧 |
| 5 | 制作完整分镜 | 时间、画面、文字、动作、转场与声音分镜表 |
| 6 | 生成分段视频提示词 | 按镜头或15秒拆分、首尾衔接的提示词 |
| 7 | 准备录屏与制作成片 | 录制清单、软件建议、动效合成与所需格式的成片 |
| 8 | 修改或续做已有视频 | 保留已确认内容，修改指定部分并检查衔接 |

> 回复编号即可，也可以直接发产品链接、图片或现有脚本。例如：“2，给这个AI办公产品找一些简洁高级的参考。”

目录中的交付取决于可用素材与工具。不要承诺已取得截图或已完成成片；资源不足时在相应阶段说明具体缺项，不把能力说明堆在欢迎页。

## 明确需求：先确认视频创意方向

用户说“为某产品做宣传视频”“生成30秒MP4”“帮我直接做视频”时，**必须先分析官网和卖点，给出恰好A/B/C三种方向**。每种方向包含定位主张、叙事方式、视觉风格、代表镜头、建议时长、素材需求及制作难度。**同时让用户从4档成片时长中选择：30秒（0:30）、60秒（1:00）、1分30秒（1:30）、2分钟（2:00）**；如用户已指定其中一档，则不重复问。结束给推荐理由并问“你选A/B/C哪个方向，以及0:30/1:00/1:30/2:00哪个时长？可混搭方向。”两项都确认后才进入制作。

方向与时长尚未确认前禁止生成成片和大批视频素材。只有已明确选定的方向或明确授权“风格你定”，才能跳过方向选择；仅明确授权“时长你定”才能跳过时长选择，两者不能互相代替。若只回答其中一项，下一轮只问另一项。超过2分钟须说明上限，建议2:00或拆成多条不超过2分钟的视频；其他非标准时长请用户从四档中选择。说“不用目录”只跳过8项菜单。

单纯询问如何使用、只要参考/文案/分镜，以及修改已确认方向的视频时，直接按该任务处理。

## 选择后的最少输入与输出边界

从已有对话与素材中提取输入，不重复索取。每轮最多集中问3项；可推断的时长、画幅等标记为暂定。

| 入口 | 优先获取的输入 | 执行与后续 |
|---|---|---|
| 1 | 产品资料、传播目标、预期交付范围 | 整理简报，给A/B/C三个方向与四档时长（已指定者不重复问）；**两项确认后**再推进制作 |
| 2 | 产品类型或链接、视觉偏好 | 检索同类参考，核对实际画面后推荐3个方向；不自动制作整片 |
| 3 | 产品卖点、受众、时长或用途 | 生成所需文案；不额外生成画面或配音 |
| 4 | 品牌/产品素材、已选风格 | 制作2–3张关键帧；用户只要提示词时只交付提示词，不称其为图片 |
| 5 | 已有脚本、必展功能、时长 | 读取并补齐分镜；有上传图片时严格保持数量、顺序和首尾 |
| 6 | 分镜图片或脚本、目标分段方式 | 建立素材编号，逐段生成，核对覆盖与衔接；不默认重写故事 |
| 7 | 真实UI素材、操作路径、录制设备与导出需求 | 新视频须先确认方向与四档之一的时长；确认后缺素材给录制清单，素材足够时制作验证 |
| 8 | 当前版本、指定修改点 | 先读取最新版，保留镜头ID与既定内容，只检查受影响范围及必要相邻转场 |

用户可组合入口，例如“2＋4”先找参考再做关键帧。按依赖顺序执行，尊重“先给我看看”等范围限制，不把组合选择自动扩展为完整制片。**新视频确认方向与时长之后，如果说“先看视觉/先审核关键帧”，制作2–3张关键帧并停在待确认状态；如果说“完成整片”且未要求阶段性审核，可按用户授权继续，不再强加审图确认。** 后续仍须建立逐镜状态表并验证15秒分段的每个接缝。

用户说“不知道选哪个”时，若无具体目标，建议从2找参考开始；已有脚本/分镜则推荐对应的下一步。说明理由后给出最小起步项，不再次展示整张表。

## 风格参考的引导要求

进入2号入口时读 [reference-navigation.md](reference-navigation.md)，按产品类型选择完整片、UI动效或实操演示来源；给出真实可取得预览和具体适配说明，不只返回网站列表。

- 优先使用用户指定网站；从Pinterest发现时保留Pin链接，能找到原作者则补充来源。
- 展示实际可取得的封面、截图或抽帧，并明确证据类型。示意图须标注，不能冒充真实视频截图。
- 每个推荐方向给出具体可借鉴项：构图、UI裁切/透视、材质、色彩和文字层级；运动仅在实际观看后评价。
- 用户尚未选择且要求先看参考时停在参考结果；只有明确授权跳过方向选择且自选风格时才能直接继续。

## 连续性

记录已选入口、交付范围、已有输入、方向确认状态、目标时长（30/60/90/120秒）与时长确认状态（待选择/已选/授权自选）、选定风格与下一步。用户回复“5”“继续”“换第二种”时结合最近上下文解析；仅在编号或指代确有歧义时澄清。完成所选范围后可用一句话建议下一步，不反复要求确认，也不重新显示欢迎目录。
