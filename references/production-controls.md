# 关键帧审阅、镜头状态与分段连续性控制

本文件是 `product-promo-director` 制作过程的可执行质量控制细则。新任务的**创意方向 A/B/C 和成片时长 0:30 / 1:00 / 1:30 / 2:00**选择仍是前置门槛；本文件不改变两项选择要求，也不允许在选择前生成成片。

## A. 关键帧审阅（可选节点，不强制逐阶段确认）

1. 方向与时长确认后，先设计 **2–3 张代表性静态关键帧**，通常为开场 KF-01、功能/核心证据 KF-02、品牌收尾 KF-03；若用户已有确认过的视觉版本，沿用，不重复生成。
2. 关键帧记录构图、品牌色、字体/字阶、真实 UI 与概念画面的边界、主角/产品/Logo 的形态、材质光线、动作预期（静态图不能证明动效）。
3. 按用户本次交付范围决定审阅模式：
   - **先看/先确认视觉**：展示可实际访问的 2–3 张图，并停在「待用户确认」；用户提出修改时局部重做，确认后再进入批量镜头制作。
   - **明确要求直接完整制作且方向/时长已确认**，或已经认可关键帧：可自动进入后续阶段，不附加新的强制确认。可先内部核查代表关键帧并记录状态，避免返工。
   - **仅需文案/分镜**：不额外生成关键帧，除非用户要求。
4. 状态字段：`未制作 / 待审阅 / 已确认 / 需修改 / 已跳过（说明原因）`；不把“已展示”当作“用户已确认”。
5. 审阅时只询问影响全片风格的关键项，例如画面层次、色调和产品 UI 真实性，不重复已经选定的方向和时长。
6. 若 KF-02 的品牌配色或 KF-03 的 Logo 修改影响其他镜头，记录影响范围，更新视觉基准与对应镜头的素材版本，必要时重新审阅受影响关键帧。

## B. 逐镜制作状态管理（每镜必有唯一ID）

从完整分镜确立后，为每个镜头记录：
- 镜头 ID（如 `SH-01`）、全片时间码、所属15秒段ID（如 `SEG-01`）、叙事目的及前后对应画面。
- 素材/真实 UI 来源、版本、文件路径或可访问链接、缺失项。
- 生成或制作工具、提示词/参数版本、视频输出路径、起始帧/结束帧证据。
- **制作状态**仅取：`待素材` / `待生成` / `待验收` / `需重做` / `已通过`；额外记录问题、修复次数、验收证据。
- 操作规则：
  1. 缺少必须素材 → `待素材`，不得虚构真实操作或宣称该镜完成。
  2. 素材准备齐全、提示词/动态方案可执行 → `待生成`。
  3. 渲染出可实际检查的视频 → `待验收`，不因渲染成功直接标记通过。
  4. 逐镜检查入场、动作峰值、落定、UI文字及与相邻镜头的接缝；有缺陷 → `需重做`，记问题与范围，仅局部返工。
  5. 检查通过且证据可访问 → `已通过`。无法播放/抽帧的内容维持 `待验收` 并写明限制，不能虚报通过。
- 每次生成一段新结果或发生修改时，更新状态表；**若仍有待素材、待生成、待验收或需重做的镜头，不能宣称成片全部通过验收**。
- 用户已有分镜时保留原始张数/顺序/首尾，用稳定镜头 ID；增加镜头要说明原因，不擅自吞镜。
- 代表镜头先行测试，在形成统一质量后再按项目所需批量制作。90秒、120秒尤其要按章节管理，不靠一次性盲生成。

## C. 15秒分段连续性协议（每个相邻段都检查）

`SEG-01..SEG-N` 只表示分段制作；用户最终视频仍是 30/60/90/120 秒，分别有 2/4/6/8 段（采用15秒固定片段时）。段内可有多镜；段界不必等于镜头界，跨段同一镜也应保持状态。

### 1. 定义每段的连续性锚点

在制作 `SEG-N` 前记录 `SEG-N-1` 最后有效帧和下一段首个有效帧的对应关系，检查：
- **主角/角色：** 形象、脸部、服饰、发型、姿态、尺度及相对位置；没有人物时登记主要产品/物体、轮廓、材质。
- **相机：** 机位、视角、景别、焦距/透视、运动方向、速度与画面重心。
- **场景：** 背景、布置、环境物体、光源方向、阴影、整体曝光、色温/品牌色。
- **UI与品牌：** 实际界面页签、页面滚动/选择/输入状态、可读文字、Logo版本、字体与色彩，不能让连续步骤无解释地切换。
- **时间与声音：** 动作阶段、上段结束时间与下段开始时间、口播断点、音乐节拍/环境声衔接。

### 2. 创建分段接口卡

每个 `SEG-N` 保留：`start_frame`、`end_frame`（实际文件或可核验时间码）；前段末尾状态说明；下一段开头状态说明；共用锚点；明确的**延续动作**或**有意设计的转场**；跨段声音交接；接缝验收状态。

- 如果是一个连续动作：下一段应从上段结束状态自然延续，不重置人物/背景/界面。必要时用前段末帧作为下一段生成参考，保持角色、UI 和相机一致。
- 如果是设计好的场景切换：允许背景与机位变化，但必须标明转场方法及其叙事意图，不能把应连续的错位当成“创意跳切”。
- 用于模型条件输入的重叠/共享锚帧属于制作辅助，**不得在最终时间线上重复计时或重复播放**。
- 文本与Logo尽量由可编辑合成层负责；不能靠视频生成重绘导致字形、品牌标识和UI内容跨段变化。

### 3. 每个接缝的验收方法

1. 对比 `SEG-N` 末帧与 `SEG-N+1` 首帧（或指定过渡对应帧），核对上述锚点。
2. **连续播放接缝前后约1–2秒**，检查主角跳变、相机方向反转、背景闪烁、UI内容重置、灯光突然改变、音频断点。
3. 有问题时记录 `SEAM-N/N+1`、具体时间码、问题与修复策略；优先仅返工相关片段/转场。
4. 接缝合格后标记 `已通过`；无法获取实际视频或未播放时标记 `待验收`，不能只凭静帧宣称运动连贯。
5. 改了任一段的首尾或音轨，必须重新检查相关相邻接缝。更改全片风格/帧率/时间线时复查所有接缝。

## D. 交付前的阶段门槛

- **创意与时长**：新项目已确认 A/B/C（或混合）和四档时长之一。
- **关键帧**：仅在用户选了“先审阅”时要求 `已确认` 才进行批量制作；选择连续制作时记录 `已跳过` 或内部基准状态。
- **逐镜状态**：所有必需镜头均 `已通过`（确实检查过的才可标记）。
- **分段接缝**：所有相邻接缝 `已通过`；若没验证，交付中明确列出未验收点。
- **最终文件**：按实际产物验证 MP4 时长、完整画面、可播放性、声音及必要素材工程。不能把提示词、预览图或仅有分镜的产物当作已完成 MP4。

## E. 项目演示（90秒宣传片）

- `KF-01/02/03` 作为视觉基准；用户若要求先审图则等待确认。
- `SEG-01..06` 6段，每段15秒；按实际故事需要包含多个稳定 `SH-xx`。
- `SH-01` 等逐镜从 `待素材→待生成→待验收→已通过` 推进，问题镜头进入 `需重做`。
- `SEAM-01/02` 至 `SEAM-05/06` 共5处接缝都核查；如果其中 `SEAM-03/04` 发生角色服装或光线跳变，局部重做 `SEG-04` 开场或设计明确转场，复核接缝。
- 只在实际具备检查证据时报告“成片验收通过”，未验证项目明确保留。
