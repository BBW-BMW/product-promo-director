# AI 视频生成详细剧本与可执行提示词规范

本阶段属于 `product-promo-director`，在**宣传文案与完整分镜均完成之后、任何视频模型逐镜生成之前**执行。目的：将“面向人阅读的导演分镜”改写为“面向当前视频模型的可执行指令”，尽量降低角色漂移、UI幻觉、跳帧、变脸、镜头运动失控、转场不连贯、错字和品牌不一致等风险。

**制作链路**：用户确认创意方向A/B/C + 时长0:30/1:00/1:30/2:00 → 产品/参考/脚本/分镜 → 关键帧（按用户要求可审阅） → **AI视频生成详细剧本（本文件）** → 代表镜头小样验证 → 全量逐镜/分段视频生成 → 合成与逐镜、接缝、整片验收。

- 这是**独立、必须真实产出的制作文档**，不能用普通分镜表、抽象一句话提示词或最终MP4代替。
- 用户仅要“脚本”或“分镜”时遵循该阶段的交付边界，不擅自生成影片。用户要求“脚本、分镜和AI视频提示词”时，应完整交付本文件定义的文本产物，但**不自动开始视频生成**；用户明确要求完整成片时，写完提示词即可按授权推进，不额外强制每阶段确认。
- 对于已有确认的剧本/分镜必须**严格沿用镜头ID、先后顺序、首尾镜、真实产品信息、字幕与口播意图**；不能为了适配模型擅自删镜或改写产品功能。确实无法生成的镜头改为录屏/编辑合成，并说明原因。

## 1. 先判断技术实现路径：不是所有镜头都让视频模型生成

逐镜设定 `method`：

| 方法 | 适用内容 | 必须做法 |
|---|---|---|
| `I2V` 图生视频 | 已有清晰关键帧、作品或场景，需自然、可控的运动 | 指定已存在的参考帧、需要保持不变的元素、主运动与最终状态 |
| `T2V` 文生视频 | 抽象概念、氛围或无精确UI要求的插画镜头 | 写清主体/场景/构图/镜头运动/运动幅度；不要请求精确小字 |
| `EDIT` 可控动效与剪辑 | 品牌字标、字幕、真实Logo、准确数值、特定UI、图表及精确转场 | 用真实截图/录屏/可编辑文字/关键帧动画，视频模型只做获准的非精确背景 |
| `RECORD` 真实录屏 | 产品操作、输入框、参数和生成结果等需核实的功能 | 记录真实操作前/点击/反馈/结果；不能让AI视频假扮可验证操作 |

如果镜头需要**精确Logo/中文文字/表单/按钮/可读UI**，优先用 `EDIT` 或 `RECORD`，禁止凭空让模型伪造界面。可做复合方案（真实UI叠加生成背景），但需标记图层边界。

## 2. 全片统一的「母提示词 / 视觉锁定表」

先生成一个全片共享的 **Global Master Prompt**，后面的逐镜提示词继承、只覆盖被明确允许变动的项目：

1. **身份与品牌锁定**：产品名、真实Logo资产路径或“未提供”、品牌色数值、字体、圆角、画面比例、不能变更的字形。
2. **场景与主角锁定**：主角/物体的细节（服装、颜色、脸部、比例、方向）、背景、道具、环境、原有素材引用、镜头空间坐标/相对位置。
3. **光线与画面风格锁定**：主光方向、阴影、材质、曝光、景深/锐化、反射、允许的微动效；不要无意义粒子/强光污染主体。
4. **运动语法**：整片统一的相机运动速度、缓入缓出、转场原则；一镜只保留一个主动作，避免同时指令冲突。
5. **后期叠加内容**：标题、字幕、口播、Logo放于后期合成的精确层，不要求视频模型直接绘制正确文字。
6. **全片负面约束 / 禁止事项**：额外人物/手指、主体变形、风格突变、镜头乱甩、过度抖动、错误按钮、乱码水印、Logo重绘、未验证的新功能。仅适用当前镜头的约束不硬塞到所有镜头。
7. **声画边界**：区分“模型原生生成音效（若可用）”与“后期BGM/口播/字幕”，避免混叠和重复。

若用户已提供真实品牌规范，以用户素材为准。未提供的Logo、参考图片、原片不得编造文件路径或宣称已锁定。

## 3. 每个镜头必须输出「导演详细剧本卡」

每个 `SH-xx` 镜头填满以下字段；缺关键信息就标为待素材或待决定，不凭空补：

- **片段与时间**：镜头ID；全片绝对时码；所属15秒逻辑分段ID（`SEG-xx`）；目标镜头时长（秒）；前后镜头ID。
- **叙事目的**：这一镜只传达哪一个功能/收益、画面证据是什么；与口播/字幕逐条对应；该镜结束后观众必须看懂什么。
- **参考与锁定**：真实品牌/产品/UI/主角/关键帧文件引用；`I2V/T2V/EDIT/RECORD`路径；哪些特征不可变；镜头优先级。
- **起始帧 (Start State)**：主体、背景、景别、机位、焦点、材质、光线、UI状态、相对坐标与画面留白。若有实际关键帧，必须引用其文件/帧号，不凭空写“已上传”。
- **逐秒动作节拍 (Timed Beats)**：按镜头时长划分可执行的若干段，如0–2秒入场、2–4秒主动作、4–6秒落定，明确“谁动、向哪儿、幅度多大、镜头怎么跟、哪些元素保持静止”。不要用15秒内同时发生大量复杂事件的一句长话。
- **相机语言**：固定/轻推/拉远/平移/跟随/微轨道；运动方向和幅度；是否允许切镜；景深和对焦变化。指定一次主相机运动，非必要不叠加旋转、缩放、翻转。
- **主体运动与物理**：主角/卡片/界面的具体变化、先后顺序、缓动、遮挡关系和可能的互动；强调位置或身份不可变。
- **终止帧 (End State)**：明确最后可识别的姿态、画面构图、对焦、UI状态和留帧；可作为下一镜/下一片段起始参考。
- **衔接**：从上一镜如何进入、向下一镜如何过渡（匹配切、遮罩、延续动作、交叉淡化等）；连续动作说明共享锚点，禁止无说明的背景/角色/相机跳变。
- **字幕与声音**：屏幕准确文字在后期叠加；口播句子与时间落点；音乐/音效建议但不伪称模型会生成正确声音。
- **单镜禁止项**：人物脸/手、角色数量、UI内容、品牌标识、文本、镜头运动或场景背景的具体禁止变化。
- **验收与失败重做**：重点检查的2–4个画面特征、可预见失败模式；失败时优先简化动作或转为可控编辑，不靠不断增加形容词。
- **生成状态**：提示词版本、目标视频模型（已知时）、模型能力已核实/待核实、素材状态和该镜验收状态。

## 4. 每镜同时交付两层提示词

### 4.1「导演版」中文详细剧本
供用户理解和审核，包含上述所有字段，并逐条对应分镜与真实功能。长片可以先按章节折叠展示，但不可漏镜或漏字段。

### 4.2「模型执行版」可直接复制的 Prompt
每镜输出单独、完整、无需从前文自行推理的生成指令，结构按以下顺序：
`[INPUT / REFERENCES]` → `[CONSISTENCY LOCK]` → `[START FRAME]` → `[MOTION / TIME BEATS]` → `[CAMERA]` → `[END FRAME / NEXT MATCH]` → `[NEGATIVE / DO NOT]` → `[POST-PRODUCTION]`。

- 默认给**中文导演说明 + 一段可直接复制的英文模型提示词**，若目标模型明确更适合中文或用户指定语言，就按其偏好输出。负面约束应符合目标工具实际语法；不假设任意模型都支持独立Negative Prompt栏。
- 执行版要短于导演版，突出**可执行的主要动作和状态**，不把全部导演评论塞给模型；长提示词不代表更能控制画面。
- 一镜若被拆为多个生成片段，每个片段独立复制可用，且必须继承主角/场景/机位/首末帧锚点。
- 视频模型通常不可靠地产生精准字幕和品牌Logo；**准确文字与品牌形状用后期叠加**。若用户要求无字幕版，不在模型提示词中要求出现字幕。

## 5. 模型适配与镜头拆解（必须核实，不能假设）

1. **使用用户指定模型**，若未指定先按当前可用制作工具选择实现路径，不为凑视频模型而伪造某厂商能力。目标模型如有文档或实际工具可查询，则核实：支持T2V/I2V/首尾帧、单次最大时长、画幅、分辨率、参考图张数、音频和提示词语言等。
2. **15秒是剧本/时间线的逻辑分段单位，不代表任何视频模型都可以一次生成15秒**。模型若单次只能生成更短片段，则按可用长度拆成多镜/短片，再在合成时汇成连续15秒章节；保持总时长和镜头ID映射。
3. 若模型不支持首尾帧、参考图、负面参数或多镜一致性，改用可用的单张参考帧、逐镜独立生成与后期匹配，明确降级策略。不编造seed、运动控制器、镜头轨迹API或其他不可用参数。
4. **复杂动作先分解**：单个镜头中不同时要求人物变装、三次场景切换、多段文字出现、UI实操和360度摄影机运动。将复杂需求拆成物理或剪辑可控的较短步骤。
5. **优先测试一镜**：挑最有代表性的镜头输出模型提示词+参考帧→生成短样片→按验收点定位问题。若出现变形/跑偏，先缩小动作、固定背景、缩减并行动作、强化参考帧，再重试；不是每镜都重复尝试同样错误。

## 6. 15秒逻辑段「可生成剧本包」

将 `SH-xx` 镜头拼成 `SEG-01 ... SEG-N`，在单镜详情之外输出对应的**段级指令卡**：

- `SEG-ID`、全片绝对时间、逻辑段内相对时间表、覆盖 `SH-xx`、目标时长与实际分镜映射。
- 统一风格与人物/物体/Logo/真实UI锁定清单；每一子镜的开始时间、结束时间、画面/运动状态。
- 前一段 `end_frame` 与本段 `start_frame` 对应；本段结尾如何接下一段；声音衔接与不可重复的共享帧。
- 若模型不支持15秒一次生成，列出本段的 **clip-01、clip-02 ...** 子片段与各自时长、模型提示词和剪辑点；子片段时长相加必须等于段时长（必要的辅助锚帧不计入播放时长）。
- 从第一张/第一镜开始，到最后品牌收尾，不漏掉用户上传的任何分镜；镜头跨段时，不用重复镜头ID来伪装全新镜头。

**固定成片时长**：0:30=2个15秒逻辑段；1:00=4段；1:30=6段；2:00=8段。严格核对所有镜头/子片段的时间加总，不能把分段生成限制强行改写为分镜结构。

## 7. AI生成提示词阶段的检查门槛

在开始视频生成**之前**逐项检查：

- 文案已完成、镜头顺序已确定、已选A/B/C与四档合法时长；若用户只是要分镜或提示词，停在相应交付边界。
- **每一镜**都有导演版详细说明、模型执行版 Prompt、起止状态、相机与主体运动、接缝、禁止项、素材路径及生成路径。
- **每个15秒逻辑段**覆盖了全镜头时间且无时间缺口/重叠；已说明目标模型是否支持单次15秒，不支持时有短片拆分表。
- 标记未提供的Logo、UI、角色参考与真实音视频为“缺失”，不虚构已获取、已验收或模型能力。
- 精确UI、中文小字、Logo、字幕分流到可控后期层；不能把文本生成成功当成系统必然能力。
- **用户要求“先看脚本、分镜和详细生成词”时**，此处交付并等待用户决定下一步；用户已授权完整制作且必要素材/工具可用时继续执行代表镜头测试，不重复强制确认。
- 任何提示词修改会记录版本并追踪影响的镜头与相邻接缝；风格规范修改需更新全片母提示词与相关镜头包。

## 8. 示例（仅演示结构，不代表真实产品功能）

**SH-03｜6秒｜I2V（假设已有真实参考图 `KF-03.png`，实际项目需核实文件存在）**

- 导演版：产品界面居中，背景深石墨。0–2秒镜头以极慢速度推进，只有右侧作品卡片出现轻微景深变化；2–4秒用户选中的卡片扩大为主视觉，保持边缘与卡片圆角；4–6秒卡片稳定占据中心，预留文字后期叠加空间。相机只做一次缓慢向前推移。结尾卡片边框对齐下一镜的起点。UI若来自真实产品，改为截图分层+可控动效，不让模型重绘按钮。
- 模型执行版（当允许用模型做该画面背景与卡片动效时）：

```text
[INPUT] Image-to-video using the provided approved reference frame.
[CONSISTENCY] Preserve the same charcoal background, original card shape, position, aspect ratio, material and soft lighting. No changes to the UI contents.
[START] Front-facing centered card with generous negative space.
[TIMELINE] 0-2s: one subtle forward camera move. 2-4s: the selected artwork card expands slightly toward center while other elements remain still. 4-6s: motion eases out, artwork locks in place.
[CAMERA] Single gentle forward dolly, no orbit, roll or sudden pan.
[END] Centered, stable artwork card with matched framing for the next shot.
[DO NOT] No new controls, no altered logo, no generated readable text, no hands, no particles, no zoom jitter, no stretching.
[POST] Add exact Chinese headline and official logo in a compositing layer, not in the generative clip.
```

示例仅为描述格式；不要把 `KF-03.png` 当成已存在的用户文件，也不假设指定模型支持每一条参数。
